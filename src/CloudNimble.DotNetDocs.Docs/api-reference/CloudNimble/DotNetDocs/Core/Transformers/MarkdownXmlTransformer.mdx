## Summary

Transforms XML documentation tags in DocEntity properties to Markdown format.

## Remarks

This transformer converts XML documentation tags to their Markdown equivalents. The traversal of the documentation
model, the skipping of strings without tags, and the resolution of `cref` references come from
[XmlTransformerBase](/api-reference/CloudNimble/DotNetDocs/Core/Transformers/XmlTransformerBase); this class only decides how each tag is written in Markdown.

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> NormalizeXmlDocIndentation <Badge color="gray">Inherited</Badge>

<Note>Inherited from `CloudNimble.DotNetDocs.Core.Transformers.XmlTransformerBase`</Note>

Normalizes indentation artifacts from XML documentation file formatting.

#### Syntax

```csharp
internal static string NormalizeXmlDocIndentation(string text)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `text` | `string` | The text to normalize. |

#### Returns

Type: `string`
The text with XML file indentation removed from all lines.

#### Remarks

[AssemblyManager](/api-reference/CloudNimble/DotNetDocs/Core/AssemblyManager) calls this when it extracts text. Trimming the extracted string strips the first line's
          leading whitespace but leaves continuation lines with their XML file indentation.
          [XmlTransformerBase.RemoveCommonIndentation](/api-reference/CloudNimble/DotNetDocs/Core/Transformers/MarkdownXmlTransformer#removecommonindentation) handles the uniform case (all lines indented);
          this method handles the mixed case where the first line has indent 0 but the
          rest share a common indent from the XML file structure.
