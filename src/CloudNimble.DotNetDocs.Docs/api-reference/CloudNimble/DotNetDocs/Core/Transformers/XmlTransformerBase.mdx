## Summary

Provides the format-neutral foundation for transformers that convert XML documentation comments into an output format.

## Remarks

This class owns everything that does not depend on the output format: walking the documentation model, deciding which
strings contain XML documentation tags, normalizing the indentation inherited from the XML documentation file, indexing
every entity so `cref` references can be resolved, and building Microsoft Learn URLs for framework types and C# keywords.

Derived classes implement [XmlTransformerBase.ConvertXml](/api-reference/CloudNimble/DotNetDocs/Core/Transformers/MarkdownXmlTransformer#convertxml) to turn the XML tags into their own format, such as
Markdown or HTML, and call [XmlTransformerBase.ResolveReference](/api-reference/CloudNimble/DotNetDocs/Core/Transformers/MarkdownXmlTransformer#resolvereference) to turn a `cref` into a [DocReference](/api-reference/CloudNimble/DotNetDocs/Core/DocReference).
