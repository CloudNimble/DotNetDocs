### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> EscapeXmlTagsInString <Badge color="gray">Inherited</Badge>

<Note>Inherited from `CloudNimble.DotNetDocs.Core.Renderers.RendererBase`</Note>

Escapes XML/HTML tag syntax for safe rendering in Markdown/MDX.

#### Syntax

```csharp
protected static string EscapeXmlTagsInString(string stringToEscape)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `stringToEscape` | `string?` | The string potentially containing XML/HTML tag syntax or generic type brackets. |

#### Returns

Type: `string`
The escaped string safe for MDX rendering.

#### Remarks

Converts angle brackets to HTML entities to prevent MDX parser interpretation as JSX/HTML tags.
This handles both generic type syntax (e.g., JsonConverter&lt;object&gt;) and XML documentation tags
(e.g., &lt;see cref="..."&gt;) by converting them to JsonConverter&amp;lt;object&amp;gt; and
&amp;lt;see cref="..."&amp;gt; respectively.

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> GetNamespaceLink <Badge color="gray">Inherited</Badge>

<Note>Inherited from `CloudNimble.DotNetDocs.Core.Renderers.RendererBase`</Note>

Gets a link to a namespace documentation page, relative to the documentation output root.

#### Syntax

```csharp
protected string GetNamespaceLink(CloudNimble.DotNetDocs.Core.DocNamespace ns, string extension, bool omitIndexFile = false)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `ns` | `CloudNimble.DotNetDocs.Core.DocNamespace` | The namespace to get the link for. |
| `extension` | `string` | The file extension (without the dot). |
| `omitIndexFile` | `bool` | [`true`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) to link to the namespace folder instead of its index file in [NamespaceMode.Folder](/api-reference/CloudNimble/DotNetDocs/Core/Configuration/NamespaceMode),
for renderers whose output platform resolves a folder link to its index page. |

#### Returns

Type: `string`
The relative link to the namespace page, using forward slashes.

#### Examples

For the namespace `CloudNimble.DotNetDocs.Core` with the extension `md`:
```csharp
// NamespaceMode.File (separator '-'):            CloudNimble-DotNetDocs-Core.md
// NamespaceMode.Folder:                          CloudNimble/DotNetDocs/Core/index.md
// NamespaceMode.Folder, omitIndexFile = true:    CloudNimble/DotNetDocs/Core
```

#### Remarks

Use this for links from the assembly index page, which sits at the output root. It shares the path logic in
[RendererBase.GetNamespaceFilePath](/api-reference/CloudNimble/DotNetDocs/Core/Renderers/YamlRenderer#getnamespacefilepath), so links always match where the namespace pages are written.

Adds this renderer's own files to the conceptual content folder. The default implementation does nothing.

#### Syntax

```csharp
public virtual System.Threading.Tasks.Task RenderPlaceholdersAsync(CloudNimble.DotNetDocs.Core.DocAssembly model)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `model` | `CloudNimble.DotNetDocs.Core.DocAssembly` | The documentation model that placeholders are being generated for. |

#### Returns

Type: `System.Threading.Tasks.Task`
A completed task.

#### Remarks

[DocumentationManager.GeneratePlaceholdersAsync](/api-reference/CloudNimble/DotNetDocs/Core/DocumentationManager#generateplaceholdersasync) writes the standard namespace and type
placeholders, then calls this method on each registered renderer. Override it to add files that a renderer needs
beyond the standard placeholders; files written into the conceptual folder are loaded with the rest of the content.
