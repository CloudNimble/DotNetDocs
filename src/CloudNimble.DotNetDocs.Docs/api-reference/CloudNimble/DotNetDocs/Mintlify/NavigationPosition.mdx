## Summary

Specifies where a template-defined tab should appear relative to generated navigation.

## Remarks

This is a DotNetDocs generation hint parsed from the `Position` attribute on a
`&lt;Tab&gt;` element in a MintlifyTemplate. It is not part of the Mintlify
`docs.json` schema and is never serialized.

## Values

| Name | Value | Description |
|------|-------|-------------|
| `Start` | 0 | The tab is emitted in template declaration order, before DocumentationReference tabs.
            This is the default. |
| `End` | 1 | The tab is appended after the root tab and every DocumentationReference tab.
            Use this for outbound href tabs such as a sibling product site. |
