## Summary

Represents per-node thumbnail overrides on a navigation item.

## Remarks

Each key overrides the nearest parent and site-level `thumbnails`.
[NavThumbnailConfig.Eyebrow](/api-reference/Mintlify/Core/Models/NavThumbnailConfig#eyebrow) is literal text; an empty string hides it.
