## Summary

Base class for navigation items that can contain groups and have external links.

## Remarks

Extends NavigationItemBase to add support for nested groups and external URLs.
Used by products and other container-level navigation elements.

#### Property Value

#### Remarks

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Searchable <Badge color="gray">Inherited</Badge>

<Note>Inherited from `Mintlify.Core.Models.NavigationItemBase`</Note>

Gets or sets whether hidden descendants remain indexed for search and llms.txt.

#### Syntax

```csharp
public System.Nullable<bool> Searchable { get; set; }
```

#### Property Value

Type: `System.Nullable<bool>?`

#### Remarks

When `true` on a hidden tab or group, descendant pages stay in site search,
`sitemap.xml`, AI assistant context, MCP search, and search-engine indexing.
The tab or group itself stays hidden. Has no effect when [NavigationItemBase.Hidden](/api-reference/Mintlify/Core/Models/NavigationItemBase#hidden) is
false. A page's own `hidden` frontmatter always wins.
See https://www.mintlify.com/docs/organize/hidden-pages.
