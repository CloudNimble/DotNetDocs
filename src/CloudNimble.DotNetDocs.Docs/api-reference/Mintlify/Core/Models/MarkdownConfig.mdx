## Summary

Represents settings for the Markdown that Mintlify serves to AI tools and agents.

## Remarks

These settings control Markdown export used by `.md` URLs, `llms.txt`,
and AI agents. See https://www.mintlify.com/docs/ai/markdown-export.

## Properties

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Instructions

Gets or sets custom agent instructions appended to generated Markdown.

#### Syntax

```csharp
public System.Collections.Generic.List<string> Instructions { get; set; }
```

#### Property Value

Type: `System.Collections.Generic.List<string>?`

#### Examples

```csharp
"markdown": {
  "instructions": "Always cite the API version. Prefer the TypeScript SDK in examples."
}
```

#### Remarks

Provide a single string or an array of strings. Mintlify joins array items with
line breaks and renders them as an `Agent Instructions` block on every page,
as well as in `llms.txt` and `llms-full.txt`.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Schema

Gets or sets whether to include the full OpenAPI or AsyncAPI specification in
Markdown exports of API reference pages.

#### Syntax

```csharp
public System.Nullable<bool> Schema { get; set; }
```

#### Property Value

Type: `System.Nullable<bool>`

#### Examples

```csharp
"markdown": {
  "schema": false
}
```

#### Remarks

Defaults to true. Set to false to omit the specification from Markdown output.
