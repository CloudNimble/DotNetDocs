## Summary

Represents a GraphQL or MCP specification reference.

## Remarks

Mintlify accepts either a string path or HTTPS URL, or an object with
[SpecRefConfig.Source](/api-reference/Mintlify/Core/Models/SpecRefConfig#source) and optional [SpecRefConfig.Directory](/api-reference/Mintlify/Core/Models/SpecRefConfig#directory). HTTP URLs are not accepted.
GraphQL defaults [SpecRefConfig.Directory](/api-reference/Mintlify/Core/Models/SpecRefConfig#directory) to `graphql-reference`.
See https://www.mintlify.com/docs/api-playground/graphql-setup.
