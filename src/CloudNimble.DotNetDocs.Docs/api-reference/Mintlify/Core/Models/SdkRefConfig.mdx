## Summary

Represents an SDK documentation artifact used to auto-populate reference pages.

## Remarks

Declare `sdk` on a tab or a group. Mintlify reads the artifact and generates
navigation groups and pages for every class, interface, module, and function.
`format` is `typedoc`, `docfx`, `javadoc`, `sphinx`,
`phpdoc`, or `go`. [SdkRefConfig.Source](/api-reference/Mintlify/Core/Models/SdkRefConfig#source) is a relative path or HTTPS URL
(HTTP is not accepted). [SdkRefConfig.Directory](/api-reference/Mintlify/Core/Models/SdkRefConfig#directory) defaults to `sdk-reference`.
Nested groups inherit the parent `sdk` unless they set their own.
See https://www.mintlify.com/docs/api-playground/sdk-reference-setup.

## Examples

```csharp
"tab": "TypeScript SDK",
"sdk": {
  "format": "typedoc",
  "source": "sdk-artifacts/typedoc.json",
  "directory": "sdk/typescript"
}
```
