## Summary

Represents code block theming for Mintlify.

## Remarks

May be a string (`system`, `dark`, or a Shiki theme name) or an object with
[CodeblocksConfig.Theme](/api-reference/Mintlify/Core/Models/CodeblocksConfig#theme) / [CodeblocksConfig.ThemePair](/api-reference/Mintlify/Core/Models/CodeblocksConfig#themepair) and optional [CodeblocksConfig.Languages](/api-reference/Mintlify/Core/Models/CodeblocksConfig#languages).
See https://www.mintlify.com/docs/organize/settings-appearance.
