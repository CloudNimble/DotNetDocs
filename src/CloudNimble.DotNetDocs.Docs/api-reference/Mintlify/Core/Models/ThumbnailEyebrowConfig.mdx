## Summary

Represents the label shown above the page title in generated thumbnails.

## Remarks

Site-wide eyebrow `source`, `style`, and `color` are set here.
Per-page or per-section thumbnail overrides use literal eyebrow text instead.
See https://www.mintlify.com/docs/organize/settings-appearance.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Source

Gets or sets the navigation level whose name appears as the eyebrow.

#### Syntax

```csharp
public string Source { get; set; }
```

#### Property Value

Type: `string?`

#### Remarks

Valid values are `group`, `tab`, `dropdown`, `anchor`,
`language`, `product`, `version`, `item`, or `none`.
If a page is not inside a navigation element of the chosen type, the eyebrow
shows the group name instead. `none` hides the eyebrow. Defaults to `group`.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Style

Gets or sets how the eyebrow is drawn on preset thumbnails.

#### Syntax

```csharp

```

#### Property Value

Type: `string?`

#### Remarks

Valid values are `plain`, `bar`, or `pill`. Defaults to `bar`
for the classic preset, `pill` for headline, and `plain` for minimal.
