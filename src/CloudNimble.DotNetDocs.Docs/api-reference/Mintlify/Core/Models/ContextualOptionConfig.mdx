## Summary

Represents a custom contextual menu option.

## Remarks

Custom options require [ContextualOptionConfig.Title](/api-reference/Mintlify/Core/Models/ContextualOptionConfig#title), [ContextualOptionConfig.Description](/api-reference/Mintlify/Core/Models/ContextualOptionConfig#description), and
[ContextualOptionConfig.Href](/api-reference/Mintlify/Core/Models/ContextualOptionConfig#href). See https://www.mintlify.com/docs/ai/contextual-menu.

## Examples

```csharp
{
  "title": "Request a feature",
  "description": "Join the discussion on GitHub",
  "icon": "plus",
  "href": "https://github.com/orgs/mintlify/discussions"
}
```
