## Summary

Represents the display settings for API parameters in the documentation.

## Remarks

Controls how API parameters are displayed in the interactive playground
and documentation pages, including whether they are expanded by default.

### <Icon icon="tag" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> Expanded

Gets or sets how parameter fields are expanded in the playground.

#### Syntax

```csharp

```

#### Property Value

Type: `string?`

#### Examples

```csharp
"params": {
  "expanded": "closed"
}
```

#### Remarks

Valid values are `all` and `closed`. Assigning `true` or `false`
(as strings) maps to `all` and `closed`. Boolean JSON tokens are not accepted.
